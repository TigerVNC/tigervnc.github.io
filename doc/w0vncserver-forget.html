w0vncserver-forget

NAME

w0vncserver-forget − forget w0vncserver display choice

SYNOPSIS

w0vncserver-forget

DESCRIPTION

w0vncserver-forget is a utility for w0vncserver(1) which will forget the stored display choice configuration.

FILES

$XDG_STATE_HOME/tigervnc/restoretoken

Default location of the restoretoken file.

SEE ALSO

w0vncserver(1),
https://www.tigervnc.org/
